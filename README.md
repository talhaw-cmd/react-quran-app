# 📖 Quran Random Ayah App

A minimalist Quran web application built with React.js that displays a random Ayah from the Holy Quran along with its Urdu translation, Surah details, and Juz (Para) number.

---

## ✨ Features

- Displays a random Ayah from the Quran
- Arabic text with proper right alignment
- Urdu translation (Jalandhri & Ahmed Ali)
- Shows:
  - Surah Name
  - Ayah Number
  - Surah Number
  - Juz (Para)
- One-click Generate button
- Fully responsive for all screen sizes
- Clean and minimalist UI using pure CSS

---

## 🛠️ Tech Stack
